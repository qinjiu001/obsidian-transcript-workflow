# Mermaid Visualizer

本目录是博客/播客转写工作流的可选配套 Skill，用于把真实流程、层级、决策或因果系统转换成兼容 Obsidian 与 GitHub 的 Mermaid 图。

## 安装位置

请将整个目录复制为：

```text
~/.codex/skills/mermaid-visualizer/
```

安装后应保留以下结构：

```text
mermaid-visualizer/
├── SKILL.md
├── LICENSE
└── references/
    └── syntax-rules.md
```
